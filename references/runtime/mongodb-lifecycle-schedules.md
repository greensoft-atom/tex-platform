# MongoDB Software Lifecycle Schedules

## What it is

A technical reference for the target runtime (doc 11). **No local copy** (technical sources are recorded as notes only).

## What the docs take from it

- MongoDB **4.4** end-of-life **February 2024**; **5.0** end-of-life **October 2024** (11 §1; 11 §1.2).
- "4.5" was a development series (odd minor versions before 5.0 were development builds), so production choices are 4.4.x or 5.0.x (11 Summary; 11 §1).
