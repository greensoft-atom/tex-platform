# STEX portal: 科商 registry and service ecosystem network

## What it is

`/keshang` is a directory of service providers registered with STEX, each with a filing-validity period and service-attribute tags. `/region/ecology` is the page of STEX's 服务生态网 (service ecosystem network) for regional technology markets, with its admission rules (dated 2022-08-09) and an application form.

## What the docs take from it

- 科商: providers with a **1-year filing period** and service tags (finance, IP, incubation, media, technology transfer) (09 §2.1).
- Regional members join STEX's network by application (09 §2.1 "Regional members (服务生态网)").

## Excerpts

1. `/keshang` — filing validity and tags (one directory entry)
   > 备案有效期：2022.11.30-2023.11.29

   *Translation:* "Filing valid: 2022-11-30 to 2023-11-29" (one year).

   > 服务属性：知识产权服务,科创孵化运营,科技咨询服务,科技媒体服务,技术转移服务

   *Translation:* "Service attributes: IP services, incubation operation, S&T consulting, S&T media, technology transfer."

2. `/region/ecology` — admission rule title
   > 上海技术交易所服务生态网入网规则

   *Translation:* "STEX Service Ecosystem Network admission rules."
