# References

This folder preserves the web sources that were searched, fetched or scraped while writing docs 01–11 (October 2026), so that every figure, rule and quotation in the docs can be traced to its source and re-checked. Each source cited in the docs has a short **reference note**; official government texts are kept in full in plain text; the raw scraped files are kept in [`raw/`](raw/).

## Copyright policy (the repository is public)

- **Notes:** one Markdown note per source with metadata, a summary, the facts the docs use and only short verbatim excerpts (at most about three sentences each) with a translation. For company and exchange pages, exchange rules, news, reports, university pages and prospectuses, the notes never reproduce more than these excerpts.
- **Official texts:** the full extracted text of official documents of state organs (laws, regulations, rules and normative notices of the State Council, NPC, ministries, STCSM, the Shanghai government and similar bodies) is in [`official-texts/`](official-texts/); PRC Copyright Law Art. 5 excludes such documents from copyright protection. Contact phone numbers, e-mail addresses and contact persons' names were removed from these plain-text copies.
- **Raw material:** at the repository owner's request, the scraped raw files (HTML, PDF, Word files, extracted text and research-tool output) are committed in [`raw/`](raw/), organised by source group. Junk was left out (empty captures, error and 403 pages, JS bundles, CDX index dumps, API probes, duplicates); no file exceeds 50 MB (the largest is 9.9 MB). [`raw-manifest.tsv`](raw-manifest.tsv) lists every collected file with source URL, archive URL, retrieval time, size, SHA-256 and whether it is in the repository.
- Third-party pages and documents in `raw/` remain the property of their publishers and are kept for research reference only.

**Note format.** Each note starts with YAML front matter: `id`, `title_zh`, `title_en`, `publisher`, `type`, `published`, `url` (original), `archived` (Wayback URL if one was used), `retrieved` (and whether the date is the file's modification time or the Wayback snapshot time), `cited_by` (doc numbers and sections, e.g. "09 §2.4"), `raw` (local raw paths) and, for official documents, `official_text`. The body has four parts: *What it is*, *What the docs take from it*, *Excerpts* (verbatim Chinese or English, each with a translation) and *Notes* (caveats and discrepancies).

**Retrieval status used in the notes.**

- *Fetched* — a copy is in `raw/` (date = file modification time of the downloaded copy, UTC). Wayback copies also give the snapshot time from the archive URL.
- *Not saved (WebFetch summary only)* — the page was read through a summarising fetch tool; the model-written summary is kept in `raw/_tool-output/webfetch-summaries/`, but it is **not** a copy of the page, so no verbatim excerpts are given.
- *Not retrieved / No local copy (cited from web search)* — the URL came from a search result or from the original ChatGPT drafts (first commit `22fd5fd`) and was never fetched; the note records only what the docs attribute to it.

**Excerpt checking.** Every blockquote excerpt was checked against the raw file with `tools/verify_excerpts.py` (170 excerpts, 0 mismatches on 2026-10-19). Whitespace, PDF page footers and line breaks are ignored in the comparison, because PDF extraction inserts them; on two-column PDF pages the lines of one column are quoted as separate fragments.
